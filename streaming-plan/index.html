片單比價：怎麼看最省

輸入想看的電影，自動查台灣有哪些平台，再算出「訂閱 + 單租」最便宜的組合。

1設定




免費申請：註冊 themoviedb.org → 設定 → API → 申請（選 Developer / 個人用途）。金鑰只存在這台裝置的瀏覽器，查詢直接從你的瀏覽器送到 TMDB。

2片單

目前是示範資料（虛構的平台組合），只是用來展示計算方式。

3對片與觀看管道

片名對錯了可以從下拉選單換。「單租價」欄可以填這部片的實際租價，留空就用下方平台預設價。

電影訂閱可看單租 / 購買單租價

4平台價格

預設月費是 2026 年各平台不綁約的最低方案，常有變動和促銷，請以官網為準。月費留空的平台不會被列入訂閱考慮；勾「已訂閱」代表你本來就有，視為 0 元。
